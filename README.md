# Day 3 - ATM Access Checker

This is a simple Python project built while learning from Dr. Angela Yu.

## What it does
It checks if a user can access an ATM based on:
- Age
- ID card
- PIN confirmation

## What I learned
- if statements
- elif statements
- else statements
- logical conditions
- user input

## How to run
Run the file using:
python day3_atm_checker.py
